# NABD planet images (design assets, not code)

Used by the shared Planet component and the Home window, exactly as on the design canvas.

| File | What it is |
|---|---|
| earth.png, mars.png | Lit, round planets for small static use |
| earth_tex.jpg, mars_tex.jpg | Flat world maps; scroll them behind a round mask to make the planet spin |
| shade_earth.png, shade_mars.png | Light-and-shadow overlays placed on top of the spinning map |
| earth_cairo_night.png | Earth at 7:40 pm Cairo time with city lights, for the Home window |

The maps came from the team's "Real Space" design file. Before submitting, check their original
source (NASA Blue Marble / Black Marble or another map) and add the credit to Layal's data log.
